```css
.x78zum5.autolayout-row[style*="justify-content: space-between"][style*="gap: 16px"] {
 display: none!important;
}
```

Nếu muốn bám **chặt hơn đúng đoạn HTML anh gửi**, dùng:

```css
div.x78zum5.autolayout-row[style*="align-items: center"][style*="justify-content: space-between"][style*="gap: 16px"][style*="position: relative"] {
 display: none!important;
}
```

Em khuyên dùng bản thứ 2 vì class `x78zum5 autolayout-row` khá chung, nếu chỉ ẩn theo class có thể làm mất các mục khác trên trang.
